# Tech Stack

## Programming Languages
- **Python**: Version 3.14 or newer. This is the primary language for implementing algorithms, data structures, and the judge system.

## Dependency Management
- **uv**: Utilized for efficient dependency resolution and package management, ensuring a consistent and isolated development environment.

## Code Quality and Analysis
- **ruff**: Employed for linting and code formatting to maintain high code quality, consistency, and adherence to Python best practices.

## Testing Frameworks
- **pytest**: Used for unit and integration testing, complementing the custom judge system for comprehensive solution verification.
- **Custom Judge System**: A core component of the project, designed to dynamically load, execute, and evaluate algorithmic solutions against predefined test cases, providing performance metrics and correctness checks.

## Version Control
- **Git**: Used for source code management, collaboration, and tracking changes.

## Development Environment (Implicit)
- **Editor-agnostic**: The project is designed to be compatible with any Python-friendly IDE or text editor.
