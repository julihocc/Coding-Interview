# Reverse a String using Stack

## Problem Description

Given a string `s`, reverse the string using a Stack data structure.

You must implement the reversal manually using a stack (pushing characters onto the stack and then popping them off), rather than using built-in string reversal functions.

## Examples

**Example 1:**
```
Input: s = "Hello"
Output: "olleH"
```

**Example 2:**
```
Input: s = "Data Structures"
Output: "serutcurtS ataD"
```

**Example 3:**
```
Input: s = "racecar"
Output: "racecar"
```

## Constraints

- `0 <= s.length <= 10^5`
- `s` consists of printable ASCII characters.
